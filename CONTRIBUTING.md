# Contributing

Thanks for helping the catalog grow.

## Suggest a post

Open an issue with the [suggest a post](https://github.com/wornoxgames/awesome-3d-prompts/issues/new?template=suggest.md) template and paste the link. Good candidates:

- a public post that shows the **result**: a video or screenshots of a game, a 3D scene or asset, an interactive toy or an animation;
- built with an AI coding model (Claude, GPT, Kimi, Gemini …), ideally with the prompt in the post;
- your own work, or someone else's public post. Either is welcome.

We review each suggestion. Accepted posts appear on [wandy3d.com/prompts](https://wandy3d.com/prompts?utm_source=github&utm_medium=referral&utm_campaign=awesome_3d_prompts) and in this list, with the author credited.

## Pull requests

Every file here is generated from the library on wandy3d.com, and the next update overwrites manual edits. Please open an issue instead of a pull request.

## Corrections and removal

If you see a wrong model, a wrong credit or a broken link, open an issue. Authors can ask for an entry to be removed; see [RIGHTS.md](RIGHTS.md).
